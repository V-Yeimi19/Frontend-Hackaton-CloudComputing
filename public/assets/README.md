# Assets Folder

## UTEC Logo

Para agregar el logo de UTEC:

1. Descarga el logo desde: https://www1.utec.edu.pe/imagenes-ti
2. Guarda el archivo como `utec-logo.png` en esta carpeta
3. El logo se mostrará automáticamente en Login, Register y Dashboard

### Nombre esperado del archivo:
- `utec-logo.png` (formato PNG recomendado)
- También soporta: `utec-logo.svg`, `utec-logo.jpg`
